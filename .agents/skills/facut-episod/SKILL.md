# Producția unui episod

1. **Citește sursa.** Notează paginile cerute, oamenii, locurile, dialogul și firul acțiunii. Uită-te la imaginile de referință și la episodul anterior. Lasă o scurtă fișă a episodului în folderul de lucru.
2. **Scrie momentele.** Pentru fiecare, fixează intenția, pozițiile de start, replica, acțiunea vizibilă și camera. Urmărește dacă personajul ține ceva, dacă mâna folosită este liberă și dacă obiectul rămâne în locul în care a fost pus. Gândește tăietura astfel încât acțiunea să rămână lizibilă.
3. **Scrie descriptorul.** Creează `episodes/<NNN-slug>/episode.json` ([formatul](../../../docs/EPISODE.md)) după modelul `episodes/002-semnul-crucii/` (scurt) și `episodes/001-painea-care-poate-sa-astepte/` (complet): decorurile (`assets/sets/`, cu ancorele lor), distribuția (`assets/characters/`), planurile, gesturile din bibliotecă (`do`, [lista](../../../docs/ENGINE.md#gesturile)), poze-cheie de braț doar unde gestul trebuie potrivit exact, recuzita și suprapunerile. Nu scrie un script Python pentru episod și nu exporta scena din Blender. Dacă îți lipsește un personaj, un decor sau un obiect, adaugă-l la constructorii din `blender/` ([contractul](../../../assets/CONTRACT.md)), apoi `npm run assets`. Pentru decorurile pictate, urmează cadrul 2, „Ograda în zori”, și [ghidul de ilustrație](../../../experiments/cleopa-painea/assets/backgrounds/README.md). Vezi întâi cadrul dificil și 2–3 cadre din gestul principal cu `npm run stills -- <episod> <cadre>` (secunde).
4. **Pregătește vocea și muzica.** Folosește `OPENROUTER_API_KEY` în mediu. Verifică modelul și setarea de voce din episodul anterior. Sincronizează audio cu `generate_audio.py` și `prepare_timeline.py` (scriu `timeline.json`), apoi `python3 tools/engine/envelopes.py <audio> episodes/<id>` pentru gură. Pune mixajul în `episodes/<id>/audio/mix.m4a`. Ascultă rezultatul, verifică ritmul replicilor și volumul muzicii sub dialog.
5. **Verifică animația.** Rulează `npm test` și `npm run check:engine -- <episod>`. Vezi cadre din pregătire, contact și revenire. Verifică mâinile în raport cu manșeta și capetele, profilul umărului, repausul și contactul cu podeaua. Orice suprapunere intenționată primește interval și motiv în `episodes/<id>/allow.json`. Recitește gesturile după `AGENTS.md`.
6. **Exportă și verifică.** `npm run export:mp4 -- <episod> --jobs 3` randează MP4-ul compact din același motor (copiază-l în `episodes/<id>/film.mp4`); verifică-l cu `ffprobe`. Pentru un film mult mai lung, folosește RunPod (skill-ul `render-runpod`). `npm run build` și `npm run preview` servesc atelierul la `127.0.0.1:4173`; episodul se vede la `/motor/?ep=<id>`. Testează filmul, derularea la un capitol și trimiterea unei observații (`node tools/engine/motor-check.mjs`). Indică în livrare linkul către film și către sursele din GitHub.
